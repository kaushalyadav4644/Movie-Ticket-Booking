A sleek, interactive, and lightweight browser-based Movie Ticket Booking application built with HTML, CSS, and JavaScript. It allows users to choose from a list of movies with predefined ticket pricing, input the number of desired tickets, and instantly calculate and book their show.

🌐 **Live Demo:** [Movie Ticket Booking](https://kaushalyadav4644.github.io/Movie-Ticket-Booking/)

---

## 🚀 Key Features

* **Movie Selection:** Choose from popular featured movies (e.g., Leo, Jailer, Vikram, Avengers) with dynamic ticket pricing.
* **Ticket Quantity Input:** Specify the exact number of tickets you wish to purchase.
* **Instant Booking Calculation:** Automatically computes the total cost and displays booking confirmation feedback.
* **Responsive UI:** Clean, modern interface optimized for a smooth user experience.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (DOM Manipulation)
* **Hosting:** GitHub Pages ([Live App](https://kaushalyadav4644.github.io/Movie-Ticket-Booking/))
